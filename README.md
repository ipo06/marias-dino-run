# Maria's Dino Run

Fertiges Geburtstags-Dinospiel fuer Maria.

## Veroeffentlichen

1. Ein neues oeffentliches Repository mit dem exakten Namen `marias-dino-run` erstellen.
2. Den Inhalt dieses Ordners direkt in das Repository hochladen.
3. Im Repository `Settings` > `Pages` oeffnen.
4. Unter `Source` die Option `Deploy from a branch` waehlen.
5. Branch `main` und Ordner `/docs` auswaehlen und speichern.
6. Die Website ist danach unter https://ipo06.github.io/marias-dino-run/ erreichbar.

Der Ordner `docs` enthaelt die fertig gebaute Website. Der uebrige Inhalt ist der
bearbeitbare Quellcode.
